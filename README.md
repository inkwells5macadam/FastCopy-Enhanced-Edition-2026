## Frequently Asked Questions

### Can I use FastCopy Enhanced Edition on older versions of Windows?
FastCopy Enhanced Edition is optimized for Windows 10 and 11. While it might work on older versions like Windows 7 or 8.1, we officially support only Windows 10 and above for the best experience.

### What happens if my copy operation is interrupted due to a power outage?
FastCopy includes resume capabilities, but for complete safety, it's recommended to use an uninterruptible power supply (UPS) for critical transfers. If interrupted, you can restart FastCopy and use the log to resume from where possible.

### Is there a way to schedule automatic backups with FastCopy?
Currently, FastCopy does not have a built-in scheduler, but you can use it with Windows Task Scheduler or other automation tools to run command-line tasks at specified times.

### How do I uninstall FastCopy Enhanced Edition?
You can uninstall it through the Windows Control Panel or Settings app. Navigate to "Apps & Features," find "FastCopy Enhanced Edition," and click "Uninstall."
